🌐 درباره پروژه

Arya Messenger یک پروژه مستقل اندرویدی با رویکرد Local-First است که با هدف ایجاد بستری برای ارتباط مستقیم بین دستگاه‌ها توسعه داده می‌شود.

هدف آریا، فراهم‌کردن زیرساخت پیام‌رسانی بدون وابستگی اجباری به یک سرور مرکزی دائمی است.

این پروژه در حال حاضر در مرحله MVP قرار دارد و تمرکز نسخه فعلی آن بر هویت دیجیتال، گفتگوهای محلی، کشف دستگاه‌ها و ارتباط در شبکه محلی (LAN) است.

«آریا هنوز یک پیام‌رسان امن و آماده استفاده عمومی نیست؛ قابلیت‌های رمزنگاری سرتاسری در نقشه راه توسعه قرار دارند.»

✨ ویژگی‌ها

🔐 هویت دیجیتال

- تولید کلید امضای P-256 در Android Keystore.
- نگهداری کلید خصوصی در محیط امن دستگاه.
- تولید کارت هویت عمومی با QR Code.
- محاسبه اثر انگشت SHA-256 کلید عمومی.
- اسکن و اعتبارسنجی QR مخاطبان.
- ذخیره مخاطبان با Room.
- امکان تأیید دستی اثر انگشت مخاطبان.

💬 پیام‌رسانی

- ایجاد گفتگوهای محلی.
- پشتیبانی از گروه‌ها.
- ذخیره پیام‌ها در پایگاه داده محلی.
- انتخاب و پیوست فایل تا سقف ۲۰ مگابایت.
- رابط کاربری چت با حباب پیام و جداکننده تاریخ.
- نمایش زمان پیام‌ها و کارت پیوست.

📡 ارتباط مستقیم (LAN)

- ارتباط آزمایشی TCP بین دستگاه‌ها.
- اتصال دستی با IP.
- کشف خودکار دستگاه‌ها با Android NSD.
- استفاده از سرویس "_arya._tcp.".
- دریافت تأییدیه ACK پس از ذخیره پیام در دستگاه مقصد.

🎨 رابط کاربری

- طراحی مبتنی بر Jetpack Compose.
- ناوبری با Navigation Compose.
- پشتیبانی از تم روشن، تاریک و سیستم.
- ذخیره تنظیمات کاربر.
- آیکون Adaptive و Monochrome.

😀 سیستم ایموجی

- Emoji Picker تصویری.
- دسته‌بندی و جست‌وجوی ایموجی‌ها.
- نمایش ایموجی‌های اخیر.
- پشتیبانی از تنوع رنگ پوست.
- استفاده از تصاویر PNG.
- نمایش تصویری ایموجی‌ها در پیام‌ها.

🛡️ امنیت و حریم خصوصی

امنیت یکی از اصول مهم طراحی آریا است؛ با این حال، نسخه فعلی هنوز زیرساخت امنیتی کامل ندارد.

موارد پیاده‌سازی‌شده

- تولید کلید خصوصی در Android Keystore.
- عدم خروج کلید خصوصی از محیط Keystore.
- نمایش کلید عمومی از طریق QR.
- تولید اثر انگشت SHA-256.
- امکان بررسی و تأیید دستی هویت مخاطب.

موارد پیاده‌سازی‌نشده

- رمزنگاری سرتاسری (E2EE).
- احراز هویت رمزنگارانه اتصال TCP.
- امضای دیجیتال پیام‌ها.
- محافظت در برابر Replay Attack.
- Forward Secrecy.
- مدیریت امن کلیدهای گروهی.
- رمزنگاری اطلاعات ذخیره‌شده (Encryption at Rest).

⚠️ هشدار امنیتی

در نسخه فعلی ارتباط TCP به‌صورت متن ساده انجام می‌شود و اطلاعات ذخیره‌شده در Room رمزنگاری نشده‌اند.

تأیید اثر انگشت نیز به‌تنهایی اتصال شبکه را امن نمی‌کند.

از این نسخه برای اطلاعات حساس استفاده نکنید.

🚀 نصب و اجرا

پیش‌نیازها

- JDK 17
- Android SDK Platform 36
- Android Build Tools 36.0.0
- Android Studio

دریافت سورس

git clone https://github.com/aversateam/Arya_messenger.git

cd Arya_messenger

اجرای تست‌ها

./gradlew :app:testDebugUnitTest

ساخت APK

./gradlew :app:assembleDebug

در ویندوز:

gradlew.bat :app:testDebugUnitTest
gradlew.bat :app:assembleDebug

فایل APK در مسیر زیر ساخته می‌شود:

app/build/outputs/apk/debug/app-debug.apk

«فایل "local.properties" در مخزن قرار ندارد و Android Studio باید مسیر SDK را متناسب با سیستم شما تنظیم کند.»

😀 منابع و مجوزهای ایموجی

بخش‌هایی از سیستم ایموجی بر اساس پروژه Telegram توسعه یافته‌اند.

اجزای اقتباس‌شده:

- "EmojiPack.java"
- "EmojiData.java"
- ساختار "EmojiView" و "EmojiTabsStrip"
- فایل "assets/emoji.pack"

این اجزا مشمول شرایط GPLv2 یا نسخه‌های بعدی آن هستند.

فایل "emoji_names.json" بر اساس داده‌های پروژه "iamcal/emoji-data" با مجوز MIT تهیه شده است.

شرایط مجوز و انتساب تصاویر ایموجی نیز باید مطابق مجوز منبع اصلی رعایت شود.

جایگزینی تصاویر ایموجی

مسیر فایل‌ها:

app/src/main/assets/emoji/<category>/<codepoint>.png

برای مثال:

flags/1f1ee-1f1f7.png

برای مشاهده فهرست فایل‌ها و کلیدواژه‌ها:

assets/emoji/INDEX.csv

تصویر جایگزین باید PNG با ابعاد ۶۴×۶۴ باشد.
