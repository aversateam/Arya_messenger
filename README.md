آریا مسنجر | Arya Messenger

Android MVP — Phase 3

آریا یک پروژه مستقل اندرویدی برای آزمایش پیام‌رسانی محلی، مدیریت هویت دیجیتال و ارتباط مستقیم بین دستگاه‌ها در شبکه محلی (LAN) است.

- Package: "dev.arya.messenger"
- Version: "0.3.0"
- Platform: Android
- Language / UI: Kotlin / Jetpack Compose

---

✨ قابلیت‌ها

🔐 هویت و مدیریت مخاطبان

- ایجاد هویت محلی با کلید امضای P-256 در Android Keystore.
- نگهداری کلید خصوصی در محیط امن Android Keystore.
- نمایش کارت هویت عمومی به‌صورت QR Code.
- تولید اثر انگشت SHA-256 از کلید عمومی.
- اسکن QR مخاطبان و اعتبارسنجی ساختار کارت هویت.
- ذخیره مخاطبان در پایگاه داده Room.
- پشتیبانی از وضعیت اعتماد مخاطب و تأیید دستی اثر انگشت.

💬 گفتگو و پیام‌رسانی

- ایجاد گفتگوهای محلی و گروه‌ها.
- ذخیره پیام‌ها در پایگاه داده محلی.
- پشتیبانی از انتخاب و پیوست فایل تا سقف ۲۰ مگابایت.
- رابط کاربری مدرن با حباب پیام، تاریخ گفتگو و زمان ارسال.
- نمایش کارت پیوست و نوار ورودی پیام.

📡 ارتباط در شبکه محلی

- ارتباط آزمایشی TCP بین دستگاه‌های متصل به یک شبکه Wi-Fi مشترک.
- امکان اتصال دستی با استفاده از IP دستگاه مقصد.
- دریافت ACK پس از ذخیره پیام در دستگاه گیرنده.
- کشف خودکار دستگاه‌های آریا با استفاده از Android NSD.
- استفاده از سرویس "_arya._tcp." برای شناسایی دستگاه‌ها در شبکه محلی.

🎨 رابط کاربری و شخصی‌سازی

- پشتیبانی از سه حالت روشن، تاریک و هماهنگ با سیستم.
- ذخیره تنظیمات ظاهری در SharedPreferences.
- ناوبری مبتنی بر Navigation Compose.
- پشتیبانی از Back Stack و دکمه بازگشت سیستم.
- آیکون مینیمال با خروجی‌های Adaptive، Monochrome و Mipmap.

😀 سیستم ایموجی

- Emoji Picker تصویری با الهام از پیام‌رسان‌های مطرح.
- استفاده از تصاویر PNG مجموعه Twemoji در رابط کاربری و ساختار فعلی ایموجی‌ها.
- دسته‌بندی ایموجی‌ها.
- جست‌وجوی ایموجی.
- نمایش ایموجی‌های اخیر.
- پشتیبانی از تنوع رنگ پوست با نگه‌داشتن ایموجی.
- درج کاراکتر Unicode ایموجی در متن پیام.
- نمایش ایموجی‌ها به‌صورت تصویر در گفتگوها.

😀 منابع و مجوزهای ایموجی

سیستم ایموجی آریا از بخش‌هایی از پروژه Telegram استفاده می‌کند.

اجزای اقتباس‌شده:

- "EmojiPack.java"
- "EmojiData.java"
- ساختار رابط کاربری مبتنی بر "EmojiView" و "EmojiTabsStrip"
- فایل داده "assets/emoji.pack" با فرمت EPK3

داده‌های دسته‌بندی و ساختار ایموجی از Telegram اقتباس شده‌اند و اجزای مربوطه مشمول شرایط مجوز GPLv2 یا نسخه‌های بعدی آن هستند.

همچنین فایل "emoji_names.json" بر اساس داده‌های پروژه "iamcal/emoji-data" تهیه شده و مشمول مجوز MIT است.

توجه: مجوز تصاویر ایموجی و حقوق مربوط به مجموعه‌های تصویری باید مطابق منبع اصلی آن‌ها رعایت شود. استفاده و توزیع این اجزا باید با شرایط مجوزهای مربوطه سازگار باشد.

جایگزینی تصویر ایموجی

تصاویر ایموجی به‌صورت فایل‌های PNG مستقل در مسیر زیر قرار دارند:

"app/src/main/assets/emoji/<category>/<codepoint>.png"

برای مثال:

"flags/1f1ee-1f1f7.png"

برای جایگزینی یک ایموجی:

1. فایل PNG موردنظر را پیدا کنید.
2. تصویر جدید با ابعاد ۶۴×۶۴ پیکسل را جایگزین کنید.
3. پروژه را مجدداً Build کنید.

فایل "assets/emoji/INDEX.csv" شامل اطلاعات پوشه، نام فایل و کلیدواژه‌های ایموجی است.

نکته فنی: ترتیب دسته‌ها و جایگاه ایموجی‌ها در آرایه "EmojiData.data" در نگاشت تصاویر مؤثر است. بنابراین جایگزینی فایل PNG موجود امن‌تر از تغییر ترتیب یا ساختار داده‌ها است.

⚠️ وضعیت امنیت و محدودیت‌ها

این نسخه یک MVP آزمایشی است و هنوز برای ارتباطات حساس یا استفاده عملیاتی امن نیست.

در Phase 3 قابلیت ثبت و تأیید دستی هویت عمومی اضافه شده است؛ اما موارد زیر هنوز پیاده‌سازی نشده‌اند:

- رمزنگاری سرتاسری پیام‌ها (E2EE).
- احراز هویت رمزنگارانه اتصال TCP.
- امضای دیجیتال پیام‌ها.
- محافظت در برابر حملات Replay.
- Forward Secrecy.
- مدیریت امن کلیدهای گروهی.
- رمزنگاری اطلاعات در حالت سکون (Encryption at Rest).

نکات مهم

- ارتباط TCP همچنان به‌صورت متن ساده انجام می‌شود.
- پیام‌ها و فایل‌های ذخیره‌شده در Room در این نسخه رمزنگاری نشده‌اند.
- تأیید اثر انگشت صرفاً یک وضعیت اعتماد محلی است و به‌تنهایی اتصال شبکه را امن نمی‌کند.
- اسکن QR به معنی تأیید هویت مخاطب نیست.
- اثر انگشت باید از طریق یک کانال مستقل و قابل اعتماد با مخاطب مقایسه شود.
- QR فقط شامل نام نمایشی و کلید عمومی است و اطلاعاتی مانند کلید خصوصی، شماره تلفن یا IP در آن قرار نمی‌گیرد.
- کشف NSD و ارتباط TCP صرفاً در شبکه محلی مشترک قابل استفاده هستند.

توصیه: از این نسخه فقط برای آزمایش با پیام‌های غیرحساس در شبکه‌های مورد اعتماد استفاده کنید.

🛠️ پیش‌نیازهای توسعه

برای Build و اجرای پروژه به موارد زیر نیاز دارید:

ابزار| نسخه
JDK| 17
Android SDK Platform| 36
Android Build Tools| 36.0.0
Gradle| Gradle Wrapper پروژه

دریافت پروژه

git clone https://github.com/aversateam/Arya_messenger.git
cd Arya_messenger

اجرای تست‌ها

./gradlew :app:testDebugUnitTest

ساخت نسخه Debug

./gradlew :app:assembleDebug

در ویندوز:

gradlew.bat :app:testDebugUnitTest
gradlew.bat :app:assembleDebug

مسیر خروجی APK

app/build/outputs/apk/debug/app-debug.apk

نکته: فایل "local.properties" عمداً در مخزن قرار نگرفته است. Android Studio باید مسیر Android SDK را متناسب با سیستم توسعه‌دهنده تنظیم کند.

🚧 برنامه توسعه

گام بعدی پروژه، آماده‌سازی زیرساخت امنیتی پیش از توسعه ارتباطات اینترنتی است.

مراحل پیشنهادی:

اصل مهم توسعه: از پیاده‌سازی الگوریتم‌های رمزنگاری سفارشی خودداری می‌شود و باید از استانداردها و کتابخانه‌های معتبر استفاده شود.
